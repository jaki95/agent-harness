**You own the resume point. Read the prior trail, don't redo it.**

Use available host filesystem, Git, execution, delegation, and matching verification tools within task authorization and host permissions. Resolve named skills through Harness's catalog rules and bundled resources from its installed package. Report unavailable tools, records, controls, or access without claiming an affected step completed. Use only the requested project's accessible records; disclose missing history or task state.

1. Locate the prior trail through the host's current-project history or transcript tools, an explicitly supplied record or agent URL, the project's saved state, or a pushed branch. Do not search unrelated projects or private chats. Read the metadata overview and last messages first, then scan back for the decision points. Parse a long transcript through available host delegation and keep the reduced timeline in the main thread (the **principle-guard-the-context-window** skill); without delegation, use bounded reads and report gaps.
2. Reconstruct operational state. The branch and worktree, what already landed (`git log`, `git diff` against the base), the open todos, the decisions made. The prior trail records earlier work and decisions. Confirm repository, branch, worktree, current heads, and landed state before resuming; reconcile drift rather than re-deriving completed work.
3. Diff done vs pending. Compare what shipped against what was planned, name the resume point, preserve completed work and reuse its applicable evidence. Recheck only claims whose current state, missing evidence, or relevance to the original goal makes it necessary; do not start a blanket verification-from-scratch pass.
4. Route the remaining work to the matching playbook and pick the verdict: continue the execution, ship a finished recommendation, ratify or override a prior conclusion, or postmortem a failed run. The pickup playbook ends here. The routed playbook owns the rest.
5. Verify the inherited claims needed for the remaining task against the original goal on the current real artifact (the **principle-prove-it-works** skill). A passing prior self-report is not the proof.
